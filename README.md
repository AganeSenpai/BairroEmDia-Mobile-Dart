# Bairro em Dia

Joao Vitor Valaitis Paulo RM:576724

Protótipo de interface mobile em Dart, sem Flutter, para apresentar o registro e acompanhamento de problemas de zeladoria urbana. Relacionado ao ODS 11 — Cidades e comunidades sustentáveis.

## Executar o protótipo

Requisito: Dart SDK 3.14.1.

```bash
dart pub get
dart run tool/build.dart
dart run tool/serve.dart
```

Abra http://localhost:8081 para visualizar o protótipo.

## Telas

Boas-vindas, início, nova solicitação, confirmação, minhas solicitações, detalhes e perfil.

A navegação, o preenchimento e os filtros são simulados. Os dados ficam apenas em memória e reiniciam ao recarregar. Não há backend, banco de dados ou integração com a API Java.
